## How do I receive my script?

Right after payment, the script is added to your Cfx.re account. Download it from [keymaster.fivem.net](https://keymaster.fivem.net/asset-grants) under **Granted Assets**.

## How do I update a script?

Download the latest version from Keymaster, then replace every file **except** `config.lua` and `locales/` if you want to keep your settings. Always read the changelog on Discord first: new options may need to be added to your config.

## Are updates free?

Yes, updates are free for life.

## Is the code encrypted?

The core of each script is protected by Cfx.re escrow. The config, translations, bridge and `editable` files stay fully open.

## Can I use the script on several servers?

The script works on every server that uses a license key from the account that bought it.

## Can I get a refund?

Delivered digital products are non-refundable. If you have an issue, contact us on Discord and we will find a solution.

## Where do I get support?

On our [Discord](https://discord.gg/Ab3vYufTh3), by opening a ticket.
